# Welcome to My Documentation Website

## Introduction

Welcome to my documentation website, created as part of Experiential Learning 12 for the Version Control Systems course.

This website demonstrates how to publish project documentation using GitHub Pages and Markdown.

## Objectives

* Learn how to create Markdown documentation.
* Organize documentation using separate pages.
* Connect pages using internal links.
* Publish a website using GitHub Pages.

## Documentation Pages

Explore the following pages:

* [Usage Guide](usage.md)
* [Frequently Asked Questions](faq.md)

## Technologies Used

* Git
* GitHub
* GitHub Pages
* Markdown

## Conclusion

This project demonstrates how GitHub Pages can be used to publish and maintain documentation online without requiring a traditional web server.
