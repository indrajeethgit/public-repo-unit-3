# Usage Guide

## Introduction

This page explains how to navigate and use this documentation website.

## Getting Started

Follow these steps to explore the website:

1. Open the homepage.
2. Read the project introduction.
3. Visit the FAQ page to learn more about GitHub Pages.
4. Use the links provided to navigate between pages.

## About GitHub Pages

GitHub Pages is a hosting service that allows users to publish static websites directly from a GitHub repository.

## Markdown Formatting

Markdown supports several formatting options:

* `#` creates a main heading.
* `##` creates a subheading.
* `-` creates a bulleted list.
* `[Link](page.md)` creates a link to another Markdown page.
* Backticks can be used to display code.
